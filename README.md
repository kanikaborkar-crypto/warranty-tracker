# Warranty Tracker

A full-stack Spring Boot web application built to track product warranties, persist upload receipts, and manage expiration timelines.

## Key Features

* **Warranty Management:** Track product purchase dates, warranty duration, and expiration timelines.
* **Document & Receipt Uploads:** Store and retrieve product receipt image files.
* **Interactive Dashboard:** View active warranties and filter items nearing expiration.

## Tech Stack

* **Backend:** Java 17, Spring Boot, Spring Data JPA
* **Frontend:** Thymeleaf, HTML5, CSS3
* **Database:** H2 Database
* **Build Tool:** Maven
